# Constraint

```typescript
interface Constraint {
    error: string;
    test: (value: any) => boolean;
}
```
An object containing 2 members : `error` and `test()`.

`test()` is a method that returns a boolean whether the provided value matches the constraint requirements.

`error` is a string that will be displayed in the error thrown by a value that did not make `test()` return `true`.
