# BoolFromStringData

```typescript
interface BoolFromStringData {
    truthy: string[];
    falsy: string[];
}
```

This interface represents the object to pass to the [`BooleanSchema`](/docs/api-reference/schemas/bool-schema)'s [`boolFromString`](/docs/api-reference/schemas/bool-schema#boolfromstring) method.
